# 🚧 DailyReportSafety (แอพรายงานประจำวัน - ทางหลวงปลอดภัย ขับขี่สบายตา V 5.0)

แอปพลิเคชันบนเว็บ (Web Application) สำหรับสร้างรูปภาพรายงานผลการปฏิบัติงานประจำวันของเจ้าหน้าที่แขวงทางหลวงปัตตานี สำนักงานทางหลวงที่ 18 กรมทางหลวง ออกแบบมาเพื่อช่วยอำนวยความสะดวกในงานสารบรรณและการรายงานความก้าวหน้าหน้างานให้มีความรวดเร็ว เป็นระเบียบ และเป็นมาตรฐานเดียวกัน

🔗 **[เข้าใช้งานระบบ (Live Demo)](https://doh-pattani.github.io/DailyReportSafety/)**

## ✨ ฟีเจอร์หลัก (Features)

*   **ระบบเลือกหน่วยงานอัตโนมัติ:** รองรับการเลือกหมวดทางหลวงและหน่วยงานภายในแขวงฯ (เช่น หมวดทางหลวงยะรัง, หมวดทางหลวงโคกโพธิ์, หมวดทางหลวงหนองจิก, งานไฟฟ้า, งานอำนวยความปลอดภัย ฯลฯ) พร้อมดึงเทมเพลตและรูปภาพผู้ควบคุมงานมาแสดงผลให้อัตโนมัติ
*   **แบบฟอร์มข้อมูลหน้างานมาตรฐาน:** สามารถระบุชื่องาน, หมายเลขสายทาง (ทล.), ชื่อตอน และช่วงกิโลเมตร (กม.) ที่ปฏิบัติงานได้อย่างครบถ้วน
*   **การจัดการรูปภาพหน้างาน:** รองรับการอัปโหลดรูปภาพและจัดเรียงลงในกรอบอินโฟกราฟิกของแขวงทางหลวงปัตตานี (แนะนำให้เลือกอัปโหลดรูปใส่ทีละกล่องเพื่อป้องกันปัญหารูปสลับตำแหน่งบนโทรศัพท์มือถือ)
*   **การส่งออกและรายงานผล (Export & Share):**
    *   📥 **จัดเก็บลงเครื่อง:** บันทึกรูปภาพรายงานที่สร้างเสร็จสมบูรณ์ลงในอุปกรณ์
    *   🔗 **แชร์รูปลงกลุ่ม Line:** ส่งรูปภาพรายงานเข้ากลุ่มไลน์ของหน่วยงานเพื่อรายงานผู้บังคับบัญชาได้ทันที

## 🚀 วิธีการใช้งาน (How to Use)

1.  เปิดเว็บแอปพลิเคชันผ่านสมาร์ทโฟนหรือคอมพิวเตอร์
2.  เลือก **หน่วยงาน** ที่รับผิดชอบจากดรอปดาวน์ลิสต์
3.  กรอกรายละเอียดข้อมูลหน้างาน: **ชื่องาน, สายทาง (ทล.), ชื่อตอน, และ กม. ที่ดำเนินงาน**
4.  คลิกที่พื้นที่อัปโหลดเพื่อ **เลือกรูปหน้างาน** ใส่ตามลำดับ
5.  ตรวจสอบความสวยงามและความถูกต้องของข้อมูลผ่านหน้าจอพรีวิว
6.  กดปุ่ม **แชร์รูปลงกลุ่ม Line** หรือ **จัดเก็บลงเครื่อง** เพื่อนำภาพไปใช้งาน
